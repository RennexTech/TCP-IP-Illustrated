Abelian Group: (V, +)

Why One's Complement Math Works for Networking
1. Closure
∀ X, Y ∈ V  ➔  (X + Y) ∈ V
  • Stays in the Family: If you add two 16-bit numbers, the result is always a valid 16-bit number.
  • No Lost Bits: Any "overflow" isn't thrown away; it is wrapped around and added back to the start (End-Around Carry).
2. Associativity
X + (Y + Z) = (X + Y) + Z
  • Grouping doesn't matter: You can sum the first half of the packet, then the second half, or vice versa.
  • Parallel Processing: Routers can split the data into chunks, calculate sums in parallel, and combine them later. The result is identical.
3. Identity Element
X + FFFF = X
  • The "Magic" Zero: In this system, FFFF (all ones) acts like Zero.
  • Neutral Action: If you add FFFF to any checksum, the value does not change.
    • Note: We use FFFF (-0) instead of 0000 (+0) to ensure robust error detection.
4. Inverses
X + X' = FFFF
  • Every Number has a Partner: For every value X, there is a complement X' (bitwise NOT).
  • The Result is Identity: When you add a number and its inverse, you get the Identity (FFFF). This allows easy verification (if Sum == FFFF, data is good).
5. Commutativity
X + Y = Y + X
  • Order doesn't matter: Header + Data is the same as Data + Header.
  • Robustness: The router doesn't need to process bytes in a strict sequence to get the correct checksum.
