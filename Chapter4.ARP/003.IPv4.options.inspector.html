8-Bit Option Type Structure
Copy (1)
Class (2)
Number (5)
Copy Bit (1 bit) 0 = Don't copy to fragments
1 = Copy to all fragments
Class (2 bits) 00 = Control / Monitor
10 = Debug / Measure
Number (5 bits) Identifies the specific option type (0-31).
Val Option Name Len Description & Usage Status
0 End of List (EOOL) 1 Marks the end of the options area. Used if options don't align to 32-bit boundary. Control
1 No Op (NOP) 1 Used for padding to align options to 4-byte boundaries. Control
