Table 9-3: IGMP & MLD Timer Parameters

Standard Reference Architecture
RV Robustness Variable
QI Query Interval
QRI Query Response Interval
Parameter Name & Meaning Default Value & Restrictions
Robustness Variable (RV) Arranges for up to RV - 1 retransmissions for state-change reports/queries. 2 (Must not be 0; Should not be 1)
Query Interval (QI) Time between general queries sent by the current querier. 125s
Query Response Interval (QRI) Maximum response time to wait for generation of reports. (Max Response field). 10s
Group Membership Interval (GMI) MLD: MALI Time passed without a report before declaring no remaining interest in a group. RV * QI + QRI (Cannot be changed)
Other Querier Present Interval MLD: Timeout Time without a general request before a non-querier declares the active querier gone. RV * QI + (0.5) * QRI (Cannot be changed)
Startup Query Interval / Count Interval and number of queries used by a querier just starting up. (0.25) * QI & RV (Count)
Last Member Query Interval (LMQI) MLD: LLQI Max response time for specific queries (Max Response field in specific queries). 1s & RV (Count)
Unsolicited Report Interval Time between retransmissions of a host’s initial state-change report. 1s
Older Version Querier Present Timeout Time a host waits without IGMPv1/v2 requests to revert back to IGMPv3. RV * QI + QRI (Cannot be changed)
Older Host Present Interval MLD: Timeout Time a querier waits without IGMPv1/v2 reports to revert back to IGMPv3. RV * QI + QRI (Cannot be changed)
