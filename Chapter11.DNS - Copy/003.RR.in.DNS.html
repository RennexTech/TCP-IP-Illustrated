DNS Resource Record (RR) Catalog

Common types used in Query/Response messages (Reference: Table 11-3)

Value Type Reference Description & Purpose
1 A [RFC1035] IPv4 AddressMaps a domain name to a 32-bit IPv4 address.
2 NS [RFC1035] Name ServerIdentifies the authoritative DNS servers for a zone.
5 CNAME [RFC1035] Canonical NameThe "Alias" record. Maps one name to another.
6 SOA [RFC1035] Start of AuthorityCore metadata: serial numbers, refresh timers, and admin contact.
12 PTR [RFC1035] PointerReverse DNS: Maps an IP address back to a name.
15 MX [RFC1035] Mail ExchangerPoints to the mail servers responsible for the domain.
16 TXT [RFC1464] TextArbitrary text. Used for SPF, DKIM, and site verification.
28 AAAA [RFC3596] IPv6 AddressMaps a domain name to a 128-bit IPv6 address.
33 SRV [RFC2782] Service SelectionDefines location (hostname/port) for specific services like SIP or XMPP.
41 OPT [RFC2671] Option (EDNS0)Pseudo-RR used to signal support for larger UDP packets.
252 AXFR [RFC1035] Full Zone TransferReplicates the entire DNS zone file to a secondary server (via TCP).
255 ANY [RFC1035] All RecordsA query type that requests every record available for a name.
