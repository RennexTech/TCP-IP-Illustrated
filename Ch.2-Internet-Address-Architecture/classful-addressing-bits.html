Understanding IP Address Classes:
An IP address is 32 bits long, divided into different sections for network and host identification. The numbers (0, 15, 16, 31) show bit positions in the address, where:
  • 0 is the first bit
  • 15-16 marks the middle section
  • 31 is the last bit
