Step 3: Perform the Calculation

The binary value 10000000 corresponds to:

1 * 27 + 0 * 26 + 0 * 25 + 0 * 24 + 0 * 23 + 0 * 22 + 0 * 21 + 0 * 20

This simplifies to: 1 * 128 = 128

128
The first octet 10000000 converts to 128 in decimal. This is the first portion of the IP address.

Step 4: Repeat for Other Octets

You can repeat this process for the remaining octets in the IP address (32.1.14). Each octet will follow the same method, and by performing the calculations for each one, you'll arrive at the full IP address in decimal.
