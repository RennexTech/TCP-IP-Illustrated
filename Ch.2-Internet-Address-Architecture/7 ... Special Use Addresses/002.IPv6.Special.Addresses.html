🌐 IPv6 Special Address Registry

Prefixes, Use Cases & References • Cheat Sheet

Prefix Special Use & Description Ref
::/0 Default Route 🛣️
The "catch-all" route. Not used for specific addressing.		 RFC5156
::/128 Unspecified Address 🚫
Used as a source IP during initialization (e.g., DHCPv6). Never a destination.		 RFC4291
::1/128 Loopback Address 🏠
The "localhost" of IPv6. Never leaves the device.		 RFC4291
::ffff:0:0/96 IPv4-Mapped 🗺️
Representing IPv4 addresses inside IPv6 sockets.		 RFC4291
64:ff9b::/96 IPv4/IPv6 Translation 🔄
Used for automatic translation (NAT64) globally.		 RFC6052
2001::/32 Teredo Tunneling 🚇
Transition mechanism for IPv6 over IPv4 UDP.		 RFC4380
2001:20::/28 ORCHIDv2 🆔
Overlay Routable Cryptographic Hash Identifiers.		 RFC7343
2001:db8::/32 Documentation 📝
Reserved for examples, books, and manuals. Like "555" in phone numbers.		 RFC3849
2002::/16 6to4 Scheme 🌉
Legacy transition mechanism for IPv6 over IPv4 networks.		 RFC3056
fc00::/7 Unique-Local 🔒
Private addresses (LAN). Similar to IPv4's 10.x.x.x or 192.168.x.x.		 RFC4193
fe80::/10 Link-Local 🔗
Used for communication on the same link (network segment). Auto-configured.		 RFC4291
ff00::/8 Multicast 📢
One-to-many communication. Replaces Broadcast in IPv6.		 RFC4291
