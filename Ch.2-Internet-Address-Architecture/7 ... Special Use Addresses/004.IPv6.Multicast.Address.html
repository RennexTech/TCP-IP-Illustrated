IPv6 Multicast Address Format

128-Bit Structure breakdown (RFC 4291)
0 8 12 16 128
1111 1111 8 Bits
Flags 4 Bits
Scope 4 Bits
Group ID 112 Bits
The 4 Flag Bits
0
R
P
T
0 Reserved. Must be zero.
R Rendezvous. Contains rendezvous point info.
P Prefix. Address based on unicast prefix.
T Transient.
0 = Permanent (Well-known)
1 = Temporary (Dynamic)
The Scope (4 Bits)

Defines how far the packet can travel. The Group ID is encoded in the low-order 112 bits.

1 Interface-Local (Loopback only)
2 Link-Local (Same LAN segment)
5 Site-Local (Within the organization)
E Global (The entire Internet)
