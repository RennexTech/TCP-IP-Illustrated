Class B IP Address Structure

Class B addresses are one of five classes (A through E) in IPv4 addressing. They are identified by their first two bits being "10" and are typically used for medium to large-sized networks.

Key Characteristics of Class B Addresses

  • Begins with binary 10
  • Network portion: 16 bits (2 fixed + 14 variable)
  • Host portion: 16 bits (can be subdivided into subnet and host IDs)
  • Range: 128.0.0.0 to 191.255.255.255
  • Default subnet mask: 255.255.0.0 (before subnetting)
  • Maximum number of networks: 16,384 (2¹⁴)
  • Hosts per network: 65,534 (2¹⁶ - 2) without subnetting
Subnetting Note: When the network administrator implements subnetting (as shown in the diagram with 8 bits), the available host addresses are subdivided. With 8 bits for subnetting:
  • Number of possible subnets: 256 (2⁸)
  • Hosts per subnet: 254 (2⁸ - 2)
  • Two addresses per subnet are reserved (network address and broadcast address)
