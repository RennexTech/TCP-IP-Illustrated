Understanding IPv6 Subnet Masks

IPv6 subnet masks are typically represented in three different ways:

  • Hex Notation: The most common way to write IPv6 addresses and masks, using hexadecimal numbers and colons.
  • Prefix Length: A simpler way to represent the mask, showing how many bits from the left are set to 1. For example, /64 means the first 64 bits are 1's.
  • Binary: Shows the actual pattern of 1's and 0's that make up the mask. This is the most detailed but least practical representation.

The /64 prefix is very common in IPv6 networks as it follows the standard practice of using the first 64 bits for the network portion and the last 64 bits for the host portion of the address.
