Understanding IP Address Classes: A Visual Guide

IP addresses are 32-bit numbers divided into different classes (A through E). Each class has specific characteristics that determine how many networks and hosts it can support. This guide explains each class in detail.

Class A
1.0.0.0 - 126.255.255.255
0NNNNNNN.HHHHHHHH.HHHHHHHH.HHHHHHHH ├─Net ID─┤├─────────Host ID────────┤
  • First bit: Always 0
  • Network bits: 8 (first octet)
  • Host bits: 24 (last three octets)
  • Networks available: 126 (2^7 - 2)
  • Hosts per network: 16,777,214 (2^24 - 2)
Example: 10.45.12.87 belongs to network 10.0.0.0
Class B
128.0.0.0 - 191.255.255.255
10NNNNNN.NNNNNNNN.HHHHHHHH.HHHHHHHH ├────Net ID────┤├────Host ID───────┤
  • First bits: Always 10
  • Network bits: 16 (first two octets)
  • Host bits: 16 (last two octets)
  • Networks available: 16,384 (2^14)
  • Hosts per network: 65,534 (2^16 - 2)
Example: 172.16.45.12 belongs to network 172.16.0.0
Class C
192.0.0.0 - 223.255.255.255
110NNNNN.NNNNNNNN.NNNNNNNN.HHHHHHHH ├──────────Net ID──────────┤├─Host─┤
  • First bits: Always 110
  • Network bits: 24 (first three octets)
  • Host bits: 8 (last octet)
  • Networks available: 2,097,152 (2^21)
  • Hosts per network: 254 (2^8 - 2)
Example: 192.168.1.45 belongs to network 192.168.1.0
Class D (Multicast)
224.0.0.0 - 239.255.255.255
1110MMMM.MMMMMMMM.MMMMMMMM.MMMMMMMM ├──────────Multicast Address────────┤
  • First bits: Always 1110
  • Purpose: Reserved for multicast groups
  • Usage: Send packets to multiple destinations simultaneously
Not used for regular host addressing
Class E (Reserved)
240.0.0.0 - 255.255.255.255
1111RRRR.RRRRRRRR.RRRRRRRR.RRRRRRRR ├───────Reserved for Research───────┤
  • First bits: Always 1111
  • Purpose: Reserved for experimental use
  • Usage: Research and development only
Not available for public use on the Internet
