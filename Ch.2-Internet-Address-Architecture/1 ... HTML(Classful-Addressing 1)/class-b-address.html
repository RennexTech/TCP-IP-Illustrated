Class B IP Address Structure

0 15 16 31
Net Number
16 bits (14 free)
Subnet ID
8 bits
Host ID
8 bits
Centrally Allocated Locally Managed at Site
Key Points:
  • This structure allows for 256 subnets (8 bits for subnet ID)
  • Each subnet can host 254 devices (8 bits for host ID, minus network and broadcast addresses)
  • Network administrators can modify this partitioning based on needs
  • The first 16 bits are centrally allocated, while the remaining bits are managed locally
