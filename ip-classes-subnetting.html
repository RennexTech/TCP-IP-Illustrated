Key Points:

  • Class A: First bit is 0, allows for largest number of host addresses
  • Class B: First bits are 10, balanced between network and host portions
  • Class C: First bits are 110, more networks but fewer hosts per network
  • Subnet bits can be varied based on organizational needs
  • More subnet bits = more subnets but fewer hosts per subnet
  • Fewer subnet bits = fewer subnets but more hosts per subnet
