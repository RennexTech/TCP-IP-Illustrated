📊 ICMPv6 Message Types (Table 8-3)

Error Messages (0-127) & Informational Messages (128-255)

Type Official Name Reference Description
Error Messages (High-order bit = 0)
1 (+) Destination Unreachable [RFC4443] Unreachable host, port, or protocol.
2 Packet Too Big (PTB) [RFC4443] Fragmentation required; used for Path MTU Discovery.
3 (+) Time Exceeded [RFC4443] Hop limit exhausted or reassembly timed out.
4 Parameter Problem [RFC4443] Malformed packet or header field error.
Informational Messages (High-order bit = 1)
128 Echo Request [RFC4443] Standard ping request; may contain optional data.
129 Echo Reply [RFC4443] Standard ping response; returns echoed data.
133 Router Solicitation (RS) [RFC4861] Host searching for routers on the link.
134 Router Advertisement (RA) [RFC4861] Router announcing presence and configuration.
135 Neighbor Solicitation (NS) [RFC4861] Searching for a neighbor's MAC (Replaces ARP).
136 Neighbor Advertisement (NA) [RFC4861] Response to NS; provides MAC address.
137 Redirect Message [RFC4861] Informs host of a better next-hop router.
144 HA Address Discovery Req [RFC6275] Mobile IPv6 Home Agent discovery.
151 Multicast Router Adv. [RFC4286] Provides address of multicast router.
