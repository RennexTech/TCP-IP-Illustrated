🛡️ IPv6 Neighbor Unreachability Detection (NUD)

State transitions for the Neighbor Cache (RFC 4861)

State Trigger / Event Action & Behavior
Incomplete
First communication attempt. Address resolution is in progress. The host sends a Neighbor Solicitation (NS) and waits for a Neighbor Advertisement (NA).
Reachable
Valid NA received. Neighbor is confirmed alive. Packets flow normally. Entry stays here for ReachableTime (default ~30s).
Stale
Timer expires in REACHABLE. Contact has not been confirmed recently. The host does not probe yet; it waits until it actually needs to send a packet.
Delay
Packet sent while in STALE. Host waits DELAY_FIRST_PROBE_TIME (5s) for upper-layer hints (like TCP ACKs) to confirm reachability before sending an ICMPv6 probe.
Probe
No confirmation during DELAY. Active probing. Sends Unicast NS messages every RetransTimer (1s). Max attempts: 3.
Deleted 💀
No replies in PROBE. Neighbor is considered dead. Entry is removed from the cache. Next packet will restart the INCOMPLETE phase.
