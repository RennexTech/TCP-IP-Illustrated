Type Code Name Use / Comment
Type 1: Destination Unreachable

16Reject Route to DestinationHit a specific 'reject' or 'null' route to that destination.

30Hop Limit Exceeded in TransitHop Limit decremented to 0. Essential for Traceroute.
31Reassembly Time ExceededFragments didn't arrive fast enough for the reassembly timer.

40Erroneous Header Field FoundGeneral header field processing error.
41Unrecognized Next HeaderUnknown value in the Next Header field (e.g. unsupported extension).
