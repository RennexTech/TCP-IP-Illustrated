The Algorithm:
1. All 16-bit words are added using 1's complement arithmetic.
2. If data length is odd, a 0x00 pad byte is appended to complete the last 16-bit word.
3. The result is bitwise inverted (NOT) and placed into the Checksum field.
💡 Note: If the calculated checksum is 0x0000, it is changed to 0xFFFF to avoid confusion with "No Checksum" (which is 0x0000 in IPv4).
