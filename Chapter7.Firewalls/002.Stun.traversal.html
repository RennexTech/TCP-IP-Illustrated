STUN Attributes Registry

Session Traversal Utilities for NAT (RFC 5389)
STUN2 Compliant
0x0001
📍MAPPED-ADDRESS Addressing
Returns the public IP/Port the server saw.
(Note: Older method. Issues with some NATs modifying payload).
0x0020
🛡️XOR-MAPPED-ADDRESS Addressing (Preferred)
The Gold Standard. Returns the public IP XORed with the transaction ID. Prevents "smart" NATs from interfering with the payload.
0x8023
🔄ALTERNATE-SERVER Redirection
"Please try this other server instead." Used for load balancing or redirection.
0x0006
👤USERNAME Security
Used for message integrity checks. Often a temporary credential exchanged via signaling (SIP/WebRTC).
0x0008
🔒MESSAGE-INTEGRITY Security
HMAC-SHA1 hash of the message. Ensures no one tampered with the packet in transit.
0x0014
🏰REALM Authentication
The "Realm" or domain name for long-term credentials.
0x0015
🎫NONCE Anti-Replay
A unique number used once to prevent Replay Attacks.
0x8028
🖐️FINGERPRINT Validation
CRC-32 Checksum. Helps distinguish STUN packets from other traffic on the same port.
0x0009
⚠️ERROR-CODE Error Handling
Similar to HTTP errors (e.g., 400 Bad Request, 500 Server Error). Contains Class + Code + Reason Phrase.
0x000A
❓UNKNOWN-ATTRS Error Handling
Lists which attributes the server didn't understand (used in 420 Unknown Attribute errors).
0x8022
💻SOFTWARE Metadata
"I am a Cisco Router" or "I am a Firefox Client". Description of the agent sending the message.
