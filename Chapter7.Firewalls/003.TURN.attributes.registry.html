TURN Attributes Registry

Traversal Using Relays around NAT
Extends RFC 5389
📡
0x0016
XOR-RELAYED-ADDRESS
The "Public IP" the server has allocated for you. You give this address to peers so they can send data to the relay.
👥
0x0012
XOR-PEER-ADDRESS
The address of the remote peer you want to talk to. Used to create permissions on the relay.
📺
0x000C
CHANNEL-NUMBER
An optimization. Instead of full headers, data is sent on a specific "Channel Number" (0x4000-0x7FFF) to save bandwidth.
⏳
0x000D
LIFETIME
How long (in seconds) the relay allocation remains active. You must refresh this before it expires.
📦
0x0013
DATA
The actual payload. If you aren't using Channel Numbers, your data sits inside this attribute.
🚆
0x0019
REQUESTED-TRANSPORT
Protocol requested (UDP or TCP). Drawn from IPv4 Protocol or IPv6 Next Header fields.
🧱
0x001A
DONT-FRAGMENT
Instructs the server to set the DF (Don't Fragment) bit on outgoing packets. Crucial for Path MTU Discovery.
⚖️
0x0018
EVEN-PORT
Requests an even-numbered port (often needed for older RTP/RTCP pairing). Can also request the next sequential port.
🎟️
0x0022
RESERVATION-TOKEN
A "ticket" to reclaim a specific reserved address/port in a subsequent request.
