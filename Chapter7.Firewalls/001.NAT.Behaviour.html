NAT Behavior Matrix

Translation vs. Filtering Logic
🔓
Endpoint-Independent
(Full Cone)
Translation Behavior
I use the SAME Public Port for everyone.
X1':x1' = Fixed
Filtering Behavior
From Y1 (Talked to) ➔ Allow
From Y2 (New) ➔ Allow
"Once the door is open, anyone can enter."
🛡️
Address-Dependent
(Restricted Cone)
Translation Behavior
I use the SAME Public Port (usually).
X1':x1' = Fixed*
Filtering Behavior
From Y1 (Talked to) ➔ Allow
From Y2 (New IP) ➔ Block
From Y1 (New Port) ➔ Allow
"Only Y1 is allowed inside."
🚫
Address & Port Dependent
(Symmetric)
Translation Behavior
I use a DIFFERENT Public Port for every destination.
X1':x1' ≠ X2':x2'
Filtering Behavior
From Y1:y1 (Exact) ➔ Allow
From Y1:y2 (Diff Port) ➔ Block
"Only the exact socket I talked to can reply."
