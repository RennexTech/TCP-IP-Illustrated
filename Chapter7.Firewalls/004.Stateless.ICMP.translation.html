Stateless IP/ICMP Translation (SIIT)

Header Translation Mechanisms RFC 6145
IPv4 ➔ IPv6
IPv6 Field (Created) Assignment Method (From IPv4)
Version Set to 6.
Traffic Class (DS/ECN) Copied directly from Type of Service (TOS) field.
Flow Label Set to 0.
Payload Length Total Length minus IPv4 Header Length.
Next Header Set to Protocol field.
Exception 1: If Protocol was 1 (ICMPv4), change to 58 (ICMPv6).
Exception 2: If fragmentation is needed (or DF=0), set to 44 (Fragment Header).
Hop Limit TTL minus 1. (If result is 0, drop packet & send ICMP Time Exceeded).
Source Address Converted via mapping function: To6(IPv4 Source, Prefix)
Dest Address Converted via mapping function: To6(IPv4 Dest, Prefix)
Fragmentation Note: If the IPv4 DF (Don't Fragment) bit is 0, an IPv6 Fragment Header is always added to warn the receiver that PMTUD was likely not used.
IPv6 Fragment Header Field Assignment Method (From IPv4)
Next Header Set to original Protocol field.
Fragment Offset Copied from Fragment Offset.
M Bit (More Fragments) Copied from MF bit.
Identification Low 16 bits = Identification. High 16 bits = 0.
IPv6 ➔ IPv4
IPv4 Field (Created) Assignment Method (From IPv6)
Version Set to 4.
IHL Set to 5 (No Options).
Type of Service Copied from Traffic Class (DS/ECN).
Total Length Payload Length + 20 (IPv4 Header size).
Identification If unfragmented: Set to 0.
If fragmented: Copied from low 16 bits of IPv6 Fragment ID.
Flags (DF / MF) Unfragmented: MF=0, DF=1.
Fragmented: MF=Copied from IPv6 M-bit, DF=0.
TTL Hop Limit minus 1.
Protocol Copied from Next Header.
Exception: If value is 58 (ICMPv6), change to 1 (ICMPv4).
Header Checksum Recomputed entirely (IPv6 has no checksum).
Source/Dest IP Converted via mapping function: To4(IPv6 Addr, Prefix)
Risk Factor: When translating fragmented IPv6 packets to IPv4, the Identification field shrinks from 32-bits to 16-bits. There is a small risk of ID collisions if distinct packets share the same lower 16 bits.
